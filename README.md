# Lisa Chuang — Personal Portfolio

A personal portfolio website showcasing my projects, skills, and background as a software developer.

## Built With

- React.js
- React Bootstrap & CSS3
- React Router DOM
- Typewriter Effect
- React TSParticles
- Node.js

## Features

- **Bilingual support** — toggle between English and Traditional Chinese
- **Multi-page layout** — Home, About, Projects, Resume
- **Responsive design** — works across desktop and mobile
- **Animated UI** — particle background, typewriter effect, tilt cards
